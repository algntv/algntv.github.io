# сайт-резюме Александра Игнатьева

Готовая одностраничная страница для публикации через GitHub Pages.

## как опубликовать

### способ 1 — в текущем репозитории проекта

1. Открой репозиторий `airbnb-berlin-price-drivers`.
2. Нажми **Add file → Upload files**.
3. Загрузи файл `index.html` в корень репозитория.
4. Открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Нажми **Save**.

Сайт будет доступен по адресу:

`https://algntv.github.io/airbnb-berlin-price-drivers/`

### способ 2 — отдельный сайт с короткой ссылкой

1. Создай публичный репозиторий с точным названием `algntv.github.io`.
2. Загрузи в него `index.html`.
3. Открой **Settings → Pages** и выбери публикацию из ветки `main`, папка `/ (root)`.

Ссылка будет:

`https://algntv.github.io/`

## что можно добавить позже

- PDF-версию резюме;
- фотографию;
- ещё 2–3 аналитических проекта;
- ссылки на hh.ru или Telegram;
- английскую версию страницы.
